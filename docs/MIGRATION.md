# План миграции со старого сайта

## Стратегия
Параллельная миграция: новый сайт работает на `new.jaluzi-peterburg.ru`, старый остаётся на `jaluzi-peterburg.ru`.

## Этапы

### 1. Подготовка (неделя 1)
- [ ] Создать новый сайт на поддомене
- [ ] Скопировать весь контент со старого сайта
- [ ] Настроить аналитику (Яндекс.Метрика)
- [ ] Подготовить redirects.csv

### 2. Тестирование (неделя 2)
- [ ] Протестировать все страницы
- [ ] Проверить формы заявок
- [ ] Проверить SEO (sitemap, robots, Schema.org)
- [ ] Протестировать админку

### 3. Переключение DNS (неделя 3)
- [ ] Настроить DNS: `jaluzi-peterburg.ru` → новый сервер
- [ ] Старый сайт → `old.jaluzi-peterburg.ru`
- [ ] Добавить редиректы со старого на новый
- [ ] Мониторинг ошибок и трафика

### 4. Пост-миграция (неделя 4)
- [ ] Мониторинг SEO (позиции, индексация)
- [ ] Исправление ошибок
- [ ] Оптимизация производительности

## Редиректы

Файл `redirects.csv`:
```csv
old_url,new_url,status_code
/gorizontal/,/gorizontal/,301
/vertical/,/vertical/,301
/rimskye/,/rimskye/,301
...
```

## SEO чеклист

- [ ] Все URL сохранены (301 редиректы)
- [ ] Sitemap.xml обновлён
- [ ] Robots.txt настроен
- [ ] Schema.org разметка на месте
- [ ] Canonical URLs правильные
- [ ] Alt-теги на изображениях
- [ ] H1, meta title, description на всех страницах

## Уведомление на старом сайте

Добавить плашку (JS):
```javascript
// Показать уведомление о переходе на новый сайт
// Через 2 недели после запуска нового
```

## Мониторинг

- Яндекс.Вебмастер: проверка индексации
- Google Search Console: проверка ошибок
- Аналитика: трафик, конверсии
- Логи сервера: 404, ошибки
