### 5. Локальный запуск

#### Вариант 1: С Docker
```bash
# 1. Запустить PostgreSQL
docker-compose -f deploy/docker-compose.yml up -d postgres

# 2. Применить миграции
cd backend
migrate -path migrations -database "postgresql://jaluzi:jaluzi_dev_password@localhost:5432/jaluzi_db?sslmode=disable" up

# 3. Настроить .env
# POSTGRES_HOST=localhost
# POSTGRES_USER=jaluzi
# POSTGRES_PASSWORD=jaluzi_dev_password
# POSTGRES_DB=jaluzi_db
# JWT_SECRET=your-secret-key-here
# NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1

# 4. Запустить backend
cd backend
go run cmd/api/main.go

# 5. Запустить frontend (в новом терминале)
cd frontend
npm install  # если еще не установлено
npm run dev
```

#### Вариант 2: Без Docker (требует локальный PostgreSQL)
Аналогично, но PostgreSQL должен быть установлен и запущен локально.
