# ADR 001: Inline-CMS подход

## Статус
Принято

## Контекст
Нужна админка для редактирования контента сайта. Требования:
- Удобство для владельца бизнеса (не технаря)
- Визуальное редактирование
- Редактирование прямо на странице, а не в отдельном интерфейсе

## Решение
Реализовать inline-CMS по принципу Figma/Webflow:
- Админка — это режим редактирования поверх самого сайта
- URL: `/page/admin` или `?admin=true`
- Блоки подсвечиваются, кликабельны, редактируемы
- Боковая панель для детального редактирования

## Последствия

### Плюсы
- Интуитивно понятно (видишь что редактируешь)
- Нет дублирования UI (один дизайн для view и edit)
- Быстрое редактирование
- Визуальная обратная связь

### Минусы
- Сложнее реализация (нужно различать режимы)
- Больше кода в компонентах (view + edit логика)
- Нужна защита от случайных изменений (авторизация)

### Риски
- Если редактор неудобный — задача провалена
- Нужно тщательно протестировать UX

## Альтернативы
1. **Отдельная админка** (WordPress-style) — отклонено, неудобно
2. **Headless CMS** (Strapi, Contentful) — отклонено, слишком сложно для задачи
3. **Inline-CMS** — выбрано
